# Chrome Web Store images

Upload the PNG files in this folder to the matching fields in the Developer Dashboard. All files are 24-bit RGB PNGs without transparency.

| Field | File | Dimensions |
| --- | --- | --- |
| Screenshots | `screenshot-general-skills-640x400.png` | 640×400 |
| Screenshots | `screenshot-junior-card-640x400.png` | 640×400 |
| Screenshots | `screenshot-junior-export-640x400.png` | 640×400 |
| Small promo tile | `promo-small-440x280.png` | 440×280 |
| Marquee promo tile | `promo-marquee-1400x560.png` | 1400×560 |

The screenshots use the three approved public examples in `documentation/images/`. The General Skills image shows the top of the tall modal at its original scale; the junior images are resized proportionally with solid margins. The marquee combines the existing Sokker++ logo and junior card. The older `store/screenshot-01.png` through `store/screenshot-05.png` show an outdated interface and should not be uploaded.
